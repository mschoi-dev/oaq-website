## 드론 스크롤 구간

- `index.html#system`: 최신 모델로 렌더링한 제품 이미지.
- `index.html#deploy`: 화면을 고정하고 스크롤 위치에 따라 카메라와 암의 접힘을 함께 제어합니다. 역방향 스크롤도 같은 경로를 되짚습니다.
- `assets/drone/scroll.js`, `scroll.css`: 기존 페이지와 분리된 동작 및 스타일.
- `oaq-drone-web.glb`: v64 모델에서 만든 약 23 MB 웹용 사본. 돌출된 축 핀과 기존 로고/도장을 포함합니다.
- `motion.json`: 시점, 중심점, 프레임, 전체 형상 맞춤 범위.
- 모델과 라이브러리는 해당 구간에 접근할 때 불러옵니다. CDN 없이 같은 사이트에서 로드합니다.
- 3D 초기화 실패 또는 데이터 절약 모드에서는 18초 제품 영상을 스크롤에 맞춰 표시합니다. `?fallback=video#deploy`로 확인할 수 있습니다.
- `prefers-reduced-motion`에서는 스크롤 보간을 생략합니다. `Continue` 링크로 긴 모션 구간을 건너뛸 수 있습니다.
- 라이브러리 라이선스: `assets/drone/LICENSE-model-viewer.txt`, `assets/drone/draco/LICENSE.txt`.

웹용 사본은 압축과 일부 메시 단순화를 적용했습니다. 원본 Blender/GLB는 수정하지 않았습니다. 모바일 화면 비율은 브라우저에서 검증했으며 실제 저사양 기기의 성능은 별도 확인이 필요합니다.

하부 탐지기는 v64에서 앞 동체와 같은 무광 차콜 색상·금속성·거칠기로 통일했습니다. 모델의 형상, 축, 애니메이션 데이터는 v63과 같습니다.


## 외부 공유용 3D 뷰어

공개 주소: https://mschoi-dev.github.io/oaq-website/drone.html

- `assets/drone/viewer.js`, `viewer.css`: 전용 뷰어. 전체/측면/OAQ 드라이브/상부 시점, 자동 회전, 접힘 슬라이더, 왕복 재생, 전체 화면, 링크 공유.

- 사용자가 직접 조작할 때만 애니메이션을 시작합니다. `prefers-reduced-motion`에서는 접기/펴기 버튼이 끝 자세로 바로 이동합니다.
- 3D 로딩 실패 시 기존 제품 동작 영상과 재시도 링크를 제공합니다.
- 로컬에서 볼 때도 HTTP 서버가 필요합니다. HTML만 분리하지 말고 `assets/drone` 폴더를 함께 호스팅하세요.

## Air / MagNav 전용 페이지

### 먼바다 INS / Quantum Navigation 비교 v09 (2026-10-24)

- `air.html?v=route9#magnav`: 기존 활주로의 근접 시점에서 출발한 뒤 GPS 두절과 함께 먼바다 상공 비교로 전환합니다. 출발/목표 전체 지도·도착 해안·도착 마커·성공/실패 종료를 제거했습니다.
- 기본 `INS only`. 반투명 기체는 현재 INS 추정 위치이며 선명한 기체는 실제 위치입니다. 민트 점선은 끝점 없는 목표 경로, 흰 실선은 최근 실제 궤적입니다.
- `Quantum Navigation (Non-GPS Navigation)`을 선택하면 추정 오차가 먼저 줄고, 실제 기체는 현재 위치/접선에서 부드럽게 선회해 경로에 합류합니다. 합류 후에도 계속 경로를 따라가며 INS로 다시 전환할 수 있습니다.
- 실제↔추정 위치 오차와 목표 경로 이탈 거리를 별도로 표시합니다. 상공/근접 전환·재생/일시정지·다시 출발·먼바다로 건너뛰기·전체 화면을 제공합니다.
- 원본 기체와 환경 자산 보존. 7개 동작 검사와 PC/모바일 크기 검증. 위치 보정과 경로 추종은 제품 기능을 설명하기 위한 가상 모션이며 실측 성능이나 실제 비행제어 구현이 아닙니다.

### 상공 시점·실제 궤적·반투명 비교 기체 v08 (2026-10-24)

- `air.html?v=overhead8#magnav`: 활주로부터 상공 시점으로 자동 출발. 선명한 실제 기체와 흰색 비행 궤적, GPS 두절 이후 목표까지 민트색 점선 경로와 반투명 비교 기체를 표시합니다.
- 반투명 기체는 같은 시각에 원래 경로를 따랐을 위치입니다. INS 추정 위치와 구별합니다. 화면에서 식별하도록 기존 모델의 상면 렌더를 확대 표시하며 실제 위치 좌표는 유지합니다.
- MagNav를 켜도 상공 시점과 전체 궤적을 유지하고, 현재 위치에서 연속 선회합니다. 목표까지 거리와 원래 경로 기체와의 거리 차이를 각각 표시합니다. 기체 추적 시 기존 3D 시점으로 돌아갑니다.
- 넓은 상공 시점용 해안 연장, 고도에 따른 수면 경계/헤이즈/깊이 정밀도 보완. 원본 기체·무장·랜딩기어 자산과 기존 비행 환경은 유지합니다. 자동 출발·GPS 경고·작은 결과 패널·다시하기·전체 화면 조작을 계승합니다.
- 경로/카메라/기록4항목, 연속 선회6항목, 비교3항목 검사. 데스크톱과 모바일 크기 확인. 가상 설명용 경로이며 실측 제품 성능 또는 실제 자동조종 시스템이 아닙니다.
