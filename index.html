02 / System

하나의 시스템, 두 개의 구성. 드론에 실리는 센싱 페이로드와 데이터를 표적으로 바꾸는 소프트웨어가 센서부터 화면까지 하나의 흐름으로 통합됩니다.

Component 01 — Airborne

Magnetic Sensing Payload

비행 중 자기장·위치·자세·시각을 하나의 타임라인으로 동기 취득해 지상으로 전송합니다. 비자성 탑재 구조와 정밀 시각 동기가 데이터 품질을 지킵니다.

  • Sensing고감도 Magnetometer + Reference 3-axis + IMU
  • PositioningGNSS / RTK 정밀 측위
  • Compute온보드 컴퓨터 · 이원 스트림 로깅
  • Link실시간 지상 전송
Component 02 — Ground

Detection & Mapping Software

수집 데이터를 보정하고 표적을 탐지·위치화하여 위성 지도 위에 좌표와 신뢰도로 표시합니다. 실험실이 아니라 임무의 관점에서 설계된 운용 화면입니다.

  • Export임무 보고서 · 좌표 데이터

03 / Technology

양자 센싱은 전장의 여섯 번째 감각이 됩니다. OAQ는 고감도 양자 자기장 센싱과 자체 탐지 알고리즘을 하나의 제품으로 통합합니다.

T-01

고감도 자기장 센싱

미세한 자기장의 흔들림까지 읽어내는 양자 기반 고감도 계측. 센서부터 시스템까지 자체 기술로 통제합니다.

T-02

플랫폼 보정

드론 자체의 자기 간섭과 환경 변화를 분리·제거하여, 움직이는 플랫폼 위에서도 신뢰할 수 있는 데이터를 만듭니다.

T-03

지능형 탐지

물리 기반 해석과 기계학습을 결합한 자체 알고리즘이 표적 후보를 자동 검출하고 위치와 신뢰도를 산출합니다.

T-04

임무 중심 소프트웨어

판단에 필요한 정보를, 판단할 수 있는 형태로. 현장의 관점에서 설계된 운용 화면과 보고 체계.
