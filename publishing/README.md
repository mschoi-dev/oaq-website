# 공동 편집 → GitHub 새 버전 게시

1. [공동 편집본](https://oaq-content-studio.minseok-choi.chatgpt.site/en/index.html?edit=1)에서 문구·이미지를 수정하고 **공유 저장**합니다.
2. 편집기 하단 **GitHub 게시**에서 **게시 화면 열기**를 누릅니다.
3. GitHub에 저장소 관리 계정으로 로그인한 상태에서 **Run workflow**를 누릅니다. Branch는 `main`, 버전은 `auto` 그대로 두고 실행하면 됩니다.
4. 실행이 초록색으로 완료되면 [전체 시안 버전](https://mschoi-dev.github.io/oaq-website/preview/)에서 새 버전을 엽니다. 실행 결과의 Summary에도 링크가 나옵니다.

[게시 작업 바로가기](https://github.com/mschoi-dev/oaq-website/actions/workflows/publish-oaq-preview.yml)

공동 편집은 링크를 가진 누구나 가능합니다. GitHub 게시 실행은 이 저장소의 쓰기 권한이 있는 계정으로 합니다. 공유 저장만으로 GitHub가 자동 변경되지는 않습니다. 게시할 때 저장돼 있던 전체 페이지를 한 번에 가져옵니다.

- 기존 홈페이지와 v54·v55 등 이전 버전은 덮어쓰지 않습니다.
- 처음은 v57, 이후 v58·v59처럼 자동 증가합니다. 원하는 새 번호를 직접 입력할 수도 있습니다.
- 업로드 이미지와 외부 이미지 주소로 교체한 이미지 모두 실제 파일을 새 버전 안에 복사합니다. 내려받을 수 없거나 지원하지 않는 이미지가 있으면 게시를 중단하며 이전 시안은 유지합니다.
- 이전 버전은 이후 공동 편집과 무관하게 그대로 유지됩니다. 문구·이미지 배치·이미지 출처·공통 메뉴·푸터·뉴스 게시물을 함께 가져옵니다.
- 게시본에는 편집 도구가 표시되지 않습니다. 편집은 공동 편집 링크에서 계속합니다.
- 재실행은 같은 GitHub 실행 ID의 기존 스냅샷을 재사용합니다. 새 게시에는 새 Run workflow를 실행합니다.
- 기존 문의 양식은 시안으로 실제 메일 발송 기능은 포함하지 않습니다.

## 유지보수

`publishing/template/en`은 공동 편집 v56의 주석 처리된 32개 HTML입니다. 레이아웃이나 필드 ID를 변경할 때 편집기 소스와 함께 갱신해야 합니다. 스타일·기본 이미지·기본 스크립트는 기존 `preview/oaq-v55`에서 복사합니다. `content-schema.json`은 내보내기 입력 검증용이며 자격증명이 없습니다.

워크플로는 GitHub가 해당 실행에만 발급한 `GITHUB_TOKEN`을 사용합니다. 별도 개인 토큰이나 공동 편집 사이트의 GitHub 자격증명 저장은 필요하지 않습니다. 기본 브랜치가 이동하면 강제 푸시하지 않고 중단합니다.

각 새 버전의 `publication.json`은 게시 시간·공유 내용의 리비전·스냅샷 해시를 기록합니다. `content-snapshot.json`에는 게시한 문구·이미지 주소가 담깁니다. 편집자 이름과 변경 이력 전체는 복사하지 않습니다.
